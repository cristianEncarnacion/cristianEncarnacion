## 🧠 Sobre mí

Soy **Ingeniero de Software Full Stack** 🇩🇴. Trabajo en integraciones bancarias con **Java / Quarkus**, construyo interfaces con **React, React Native y TypeScript** y mantengo proyectos open source en **Rust** y **Java**.

```javascript
  frontend: ["React", "React Native (Expo)", "TypeScript", "Next.js", "Tailwind CSS"],
  data: ["PostgreSQL", "MySQL", "Redis", "Kafka", "Supabase"],
  devops: ["Docker", "GitHub Actions", "Keycloak (OIDC)"],
  currentlyBuilding: [
    "ferroreport — motor de reportes open source en Rust 📊",
    "PagosRD — capa de pagos (AZUL / CardNET) para plataformas dominicanas 🚀"

```

- 📊 Autor de **[ferroreport](https://github.com/cristianEncarnacion/ferroreport)**, motor de reportes en Rust que lee las plantillas de JasperReports: una factura en 11 ms (JasperReports tarda 2.6 s), para JavaScript, Python, Java, Rust y Docker.
- 🧪 Autor de **[cassette4j](https://github.com/cristianEncarnacion/cassette4j)**, graba las llamadas a LLMs y las repite en los tests de Java. Publicada en Maven Central.
- 🏦 Backend en el sector bancario: APIs y microservicios con **Quarkus** en producción; **Spring Boot** y **Node.js** en proyectos propios.
- 💳 Autor de **[@pagosrd/azul](https://www.npmjs.com/package/@pagosrd/azul)**, SDK open source en TypeScript para la pasarela de pagos AZUL.
- 📱 Apps web y móviles multiplataforma con React y React Native.
- 🎯 Abierto a oportunidades remotas como **Backend / Full Stack Engineer**.
